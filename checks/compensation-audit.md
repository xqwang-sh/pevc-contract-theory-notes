# 报酬模型一节：发布前审查

2026-10-19。对应 GitHub Issue #1。

## 文献、教学推导与算例的边界

- 文献框架：Gompers–Lerner（1999）第 3.1、3.2 节及附录 A、B。学习模型是能力的初始对称不确定与隐藏努力；纯信号模型是 GP 已知类型、LP 未知，类型通过合同选择揭示。两套信息假设分别讨论。
- 本讲从明确写出的线性收入与预期净收益均分规则推出 f2=a2+beta*m1、beta=1/2-nu2。固定第二期系数，结合市场按预期努力更新能力，推出给定合同下的 C'(e1)=nu1+delta*beta*kappa。
- 该教学表达不是论文两期最优合同的数值复现，也不以它代替原文闭式求解。论文关于新老机构合同的比较另行标明为原文预测。beta 为正需要 nu2<1/2，正文已经说明。
- 学习均值上升与最优业绩系数变化分开；没有从 m1 上升直接推出 nu2 上升。
- 信号部分说明风险成本、不同能力对同一系数变化的不同吸引力，以及两条类型 IC。0.5 的相对优势不被称为已经验证的分离均衡；类型 IC 要包含冒充后获得的未来合同。

## 冷读发现并修正的口径问题

原讲义使用两期合并的 CARA 效用，但附录把第二期确定性等价的风险系数直接取为期初 r。现在正文先明确完整效用，第二期以该期收入单位表示的条件风险系数为 r2=r*delta。数值条件下为 0.8，第二期 GP 净确定性等价由 1.640625 修正为 1.65；预期净收入 1.6875 不变。两期合计风险中的 delta^2 与此一致。由于风险项在给定合同下不随努力变动，e1=e2=1 的努力结论不变。

同时将“只需某个分成系数”改为“在给定教学合同下系数为……”，并在引入模型时提前说明教学推导与原文最优合同结论的区别。
