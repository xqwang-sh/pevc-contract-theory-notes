# PE/VC 合同理论学生讲义

面向金融学博士生的两次课网页讲义，假定学生已经学习高级微观、高级宏观和基础计量，但尚未系统学习委托代理、不完全合同或 VC 条款。

在线阅读：[pevc-contract-theory-notes.netlify.app](https://pevc-contract-theory-notes.netlify.app/)

## 讲义内容

- 第 5 周：基金层合同、GP 激励与 LPA 治理
- 第 6 周：投资层合同、状态依赖控制与分阶段融资
- 每讲均包含 80 分钟课堂主线、课后自学附录、模型推导、数值练习和经典文献导读

直接打开 `docs/index.html` 即可进入课程首页。`docs/` 中的 HTML 已嵌入样式、脚本和数学公式资源，适合离线阅读。

## 重新生成网页

安装 [Quarto](https://quarto.org/) 后，在仓库根目录运行：

```bash
quarto render
```

生成结果保存在 `docs/`。课程首页 `docs/index.html` 是独立维护的入口页。

## 教学说明

课堂主线强调经济问题、时序、激励约束和制度边界；较完整的模型推导与论文阅读放在附录，学生可按“最低复习—机制进阶—研究阅读”三条路径自学。

中国法律与监管内容仅用于说明经济权利需要具体法律载体和执行程序，不构成具体交易的法律意见。
