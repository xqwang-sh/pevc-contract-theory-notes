PE/VC 合同理论
学生讲义

沿着同一元钱的旅程，先理解 LP 如何把长期资本交给 GP，再理解 VC 为什么要把企业层的支付权、控制权和后续融资权分开配置。

适用基础：已经学习高级微观、高级宏观和基础计量，但没有系统学习委托代理、不完全合同或 VC 条款。正文只要求会比较预期效用、理解不等式和基本 NPV；所有新符号都会在首次出现时解释。

建议学习顺序

  1. 先读问题和制度事实。先说清参与者、时间线和信息差，不急着背条款。
  2. 独立完成数字例题。先写候选支付和口径，再展开答案核对。
  3. 把数字翻译成公式。每条公式都要能用中文解释左右两边。
  4. 回到真实合同与论文。区分制度描述、条款算术、理论机制和因果识别。
  5. 完成 Exit ticket。用“摩擦—权利—行动—结果—替代解释”分析一项条款。
  6. 按需进入附录。先选一套模型，再选一篇锚点论文；不要求一次读完全部扩展。
难度提示：两次课的 80 分钟主线难度约为 3/5；课后模型与经典文献附录约为 4/5。最重要的不是完成复杂求导，而是保持分析层次清楚：支付公式不能自动回答控制问题，理论比较静态也不能自动变成现实条款的因果效果。附录有独立阅读路径、预计时间和产出要求，不属于课堂硬性讲授内容。
